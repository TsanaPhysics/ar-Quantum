หลักฟิสิกส์การคำนวณควอนตัม FORMULAS

• นิยามคิวบิตบนทรงกลมบล็อค ---- $|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$ ทุกจุดบนผิวทรงกลมหนึ่งหน่วยแทนสถานะควอนตัมบริสุทธิ์ของ 1 คิวบิต

• เกตฮาดามาร์ด (Hadamard Gate) ---- $H = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$ หมุนเวกเตอร์รอบแกน $\frac{X+Z}{\sqrt{2}}$ ด้วยมุม $\pi$ สร้างสถานะซ้อนทับเท่ากัน $|+\rangle$

• ลำดับพัลส์ Hahn Spin Echo ---- พัลส์ $\pi_y$ หลังเวลา $\tau$ จะกลับทิศทางของสปินที่สลายเฟส ($T_2^*$) ให้วิ่งย้อนกลับมารวมตัวกันที่เวลา $2\tau$ เกิดสัญญาณเอคโคความเข้มข้นสูงสุด

• การสร้างภาพตัดขวางควอนตัม (Quantum State Tomography) ---- กู้คืนเมทริกซ์ความหนาแน่นเต็มรูป $\rho = \frac{1}{2}(I + \langle X\rangle\sigma_x + \langle Y\rangle\sigma_y + \langle Z\rangle\sigma_z)$ จากการวัดบน 3 ฐานพิกัด

📊 สถิติการตรวจวัดควอนตัมแบบจำลอง 1,000 ครั้ง (Born Rule Sampling)
ผลการวัด |0⟩ ---- 0 ครั้ง (0%) ผลการวัด |1⟩ ---- 0 ครั้ง (0%)

สมาชิกทแยงมุม $\rho_{00}, \rho_{11}$ แทนความน่าจะเป็นประชากร (Populations) ขณะที่สมาชิกนอกแนวทแยง $\rho_{01}, \rho_{10}$ แทนสภาพเชื่อมแน่นเชิงควอนตัม (Quantum Coherences) ซึ่งจะหดเล็กลงเมื่อเกิดการรบกวนจากสิ่งแวดล้อม (Dephasing)
