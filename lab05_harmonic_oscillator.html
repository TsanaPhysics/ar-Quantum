หลักฟิสิกส์สำคัญประจำบท FORMULAS

• ระดับพลังงานขั้นบันได ---- $E_n = \left(n + \frac{1}{2}\right)\hbar\omega$ โดยที่ระยะห่างระหว่างระดับเท่ากันเสมอ $\Delta E = \hbar\omega$

• ฟังก์ชันคลื่นพหุนามแอร์มีต ---- $\psi_n(x) = \frac{1}{\sqrt{2^n n! \sqrt{\pi} x_0}} H_n\left(\frac{x}{x_0}\right) e^{-\frac{x^2}{2x_0^2}}$

• ตัวดำเนินการบันได ---- $\hat{a}^\dagger |n\rangle = \sqrt{n+1}|n+1\rangle$ และ $\hat{a}|n\rangle = \sqrt{n}|n-1\rangle$

• สถานะอาพันธ์เกลาเบอร์ ---- $|\alpha\rangle = e^{-\frac{|\alpha|^2}{2}} \sum_{n=0}^\infty \frac{\alpha^n}{\sqrt{n!}}|n\rangle$ เคลื่อนที่แบบฮาร์มอนิกโดยซองคลื่นไม่แผ่กว้างออกตามกาลเวลา

🌌 การแจกแจงเสมือนความน่าจะเป็นวิกเนอร์ W(x, p) ในปริภูมิเฟส
สถานะปัจจุบัน ---- Fock State |0⟩ เครื่องหมายควอนตัมลบ ---- W(x, p) < 0 บ่งบอก Non-classicality

สำหรับสถานะฟ็อกก์ $|n\rangle$ การแจกแจงวิกเนอร์ $W_n(x, p) = \frac{(-1)^n}{\pi\hbar} e^{-\rho^2} L_n(2\rho^2)$ จะแสดงวงแหวนสลับที่มีค่าติดลบ ซึ่งเป็นคุณสมบัติควอนตัมแท้บริสุทธิ์ ขณะที่สถานะอาพันธ์ $|\alpha\rangle$ จะเป็นวงกลมเกาส์เซียนหมุนวนรอบจุดกำเนิดอย่างราบรื่น

📊 การแจกแจงจำนวนโฟตอนของสถานะอาพันธ์ P(n)
จำนวนโฟตอนเฉลี่ย ⟨n⟩ ---- 2.56 การแจกแจงแบบปัวซง ---- Δn = √⟨n⟩

สถานะอาพันธ์มีความน่าจะเป็นที่จะตรวจพบ $n$ โฟตอนเป็นไปตามกฎของปัวซง $P(n) = e^{-|\alpha|^2} \frac{|\alpha|^{2n}}{n!}$ โดยมีค่าความไม่แน่นอนของจำนวนอนุภาค $\Delta n = \sqrt{\langle n \rangle}$ ซึ่งสอดคล้องกับแสงเลเซอร์อุดมคติในทัศนศาสตร์ควอนตัม
