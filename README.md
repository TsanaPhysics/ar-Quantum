# ar-Quantum

ห้องปฏิบัติการเสมือนจริงควอนตัมฟิสิกส์ 3 มิติ WebAR & PWA (RBRU Quantum AR Interactive Simulation)  
ประกอบตำราวิชาการ: **"ควอนตัมฟิสิกส์เบื้องต้น: การประยุกต์ภาพเสมือนจริงสามมิติและโครงข่ายประสาทเทียมตามหลักฟิสิกส์"**  
**ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา**  
สาขาวิชาดิจิทัลการเกษตรและสิ่งแวดล้อม คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี

---

## 🔬 รายการสถานีปฏิบัติการเสมือนจริง (12 WebAR Labs)

1. **[LAB 01: การแผ่รังสีของวัตถุดำและโฟโตอิเล็กทริก](lab01_blackbody_photoelectric.html)** (บทที่ 1)
2. **[LAB 02: การแทรกสอดช่องคู่ของอิเล็กตรอนเดี่ยว](lab02_double_slit.html)** (บทที่ 2)
3. **[LAB 03: สมการชเรอดิงเงอร์และแพ็กเก็ตคลื่น](lab03_schrodinger_wavepacket.html)** (บทที่ 3)
4. **[LAB 04: ควอนตัมทันเนลลิงและกล้อง STM ระดับอะตอม](lab04_quantum_tunneling.html)** (บทที่ 4)
5. **[LAB 05: ตัวแกว่งกวัดฮาร์มอนิกและสถานะอาพันธ์](lab05_harmonic_oscillator.html)** (บทที่ 5)
6. **[LAB 06: ออร์บิทัลอะตอมไฮโดรเจนและสปิน 3 มิติ](lab06_hydrogen_orbitals.html)** (บทที่ 6)
7. **[LAB 07: การควบแน่นโบส-ไอน์สไตน์และสถิติควอนตัม](lab07_bec_quantum_statistics.html)** (บทที่ 7)
8. **[LAB 08: ทรงกลมบล็อคสามมิติและเกตควอนตัม](lab08_bloch_sphere.html)** (บทที่ 8)
9. **[LAB 09: ความพัวพันควอนตัมและการทดสอบ CHSH](lab09_quantum_entanglement.html)** (บทที่ 9)
10. **[LAB 10: สถาปัตยกรรมชิปควอนตัมและอัลกอริทึมโกรเวอร์](lab10_grover_hardware.html)** (บทที่ 10)
11. **[LAB 11: การแปลงฟูเรียร์ควอนตัมและอัลกอริทึมของชอร์](lab11_qft_shor_algorithm.html)** (บทที่ 10)
12. **[LAB 12: การแจกจ่ายกุญแจรหัสลับควอนตัม (QKD Network)](lab12_quantum_cryptography_qkd.html)** (บทที่ 9)

## 🚀 เทคโนโลยีหลัก (Key Technologies)

* **3D Engine**: Three.js (r128) WebGL / PBR Shaders
* **AI Gesture Tracking**: Google MediaPipe Hands (21-Joint Landmark Detection)
* **PWA & Offline**: Service Worker (`sw.js`) Cache-First Architecture + Web App Manifest
* **Audio Synthesis**: Web Audio API Procedural Synthesizer (0-byte audio asset)
* **Math Rendering**: MathJax 3 & KaTeX
