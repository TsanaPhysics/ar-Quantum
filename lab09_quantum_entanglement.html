🚀 ไดอะแกรมวงจรเทเลพอร์ตควอนตัม (Quantum Teleportation Circuit)
ความแม่นยำการกู้คืนสถานะ (Fidelity) ---- F = 100.00 % บิตคลาสสิกที่ส่งผ่านเส้นใยนำแสง ---- m₁ m₂ = 0 0

Alice ใช้เกต CNOT และเกต Hadamard บนคิวบิตนิรนาม $|\psi\rangle$ ร่วมกับคิวบิตพัวพันคู่ที่ 2 จากนั้นวัดผลในฐานเบลล์ (Bell State Measurement) เพื่อส่งบิตคลาสสิก 2 บิตไปยัง Bob จากนั้น Bob จะใช้เกต $Z^{m_1} X^{m_2}$ เพื่อกู้คืนสถานะ $|\psi\rangle$ ดั้งเดิมกลับคืนมาได้ 100% โดยไม่มีการส่งอนุภาคทางกายภาพข้ามระยะทาง

🔮 การพิสูจน์ความไม่เฉพาะที่แบบเด็ดขาด (Mermin's GHZ Non-Locality)
ทฤษฎีตัวแปรแอบแฝงเฉพาะที่ (Local Realism) กำหนดว่าการวัดของแต่ละสถานีมีผลลัพธ์แน่นอนล่วงหน้า $m_x, m_y \in \{+1, -1\}$ ----
• การวัดที่ 1 ---- X₁ Y₂ Y₃ = (m_{x1})(m_{y2})(m_{y3}) = +1
• การวัดที่ 2 ---- Y₁ X₂ Y₃ = (m_{y1})(m_{x2})(m_{y3}) = +1
• การวัดที่ 3 ---- Y₁ Y₂ X₃ = (m_{y1})(m_{y2})(m_{x3}) = +1
เมื่อคูณสมการทั้ง 3 เข้าด้วยกัน ---- (m_{x1} m_{x2} m_{x3}) (m_{y1} m_{y2} m_{y3})² = +1
เนื่องจาก (m_y)² = 1 เสมอ ดังนั้น คลาสสิกทำนายเด็ดขาดว่า ---- X₁ X₂ X₃ = +1
แต่กลศาสตร์ควอนตัมให้ผลลัพธ์ตรงกันข้ามอย่างสิ้นเชิง ---- X₁ X₂ X₃ |GHZ⟩ = -1 |GHZ⟩ เสมอ!
